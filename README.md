# Opeyemi Victor Obasuyi — Website

Portfolio site for Opeyemi Victor Obasuyi, camera department crew for film and TV (Lagos & UK).
Designed and built by JayDev Studio.

## Stack

- Next.js 14 (App Router) + TypeScript, every page statically generated
- Tailwind CSS: colours, type scale and radii live in `tailwind.config.ts`
- Framer Motion: page transitions, split-text headings, scroll-lit text, image reveals, parallax, magnetic buttons,
  counters, marquees, sliding nav pill, scroll progress bar, mobile menu, camera hotspots, film-strip timeline, lightbox
- `next/image` with AVIF/WebP, blur placeholders for local photos
- Self-hosted fonts via Fontsource: Big Shoulders Display, Instrument Serif, DM Sans, IBM Plex Mono

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build check before pushing
```

Deploy by pushing to GitHub and importing the repo into Vercel. No environment variables are needed.
